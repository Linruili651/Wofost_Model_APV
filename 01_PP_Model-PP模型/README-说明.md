# PP Model-PP模型

Run `Run_PP-运行PP.ipynb` or `Run_PP-运行PP.py`. / 运行本目录的 PP 笔记本或 Python 入口。

The model is Wofost73_PP, with no water limitation. Six crops share the same core as WLP. / 模型为 Wofost73_PP，水分不限制生长；六种作物与 WLP 使用同一共享引擎。

Dependencies: the other five folders must remain alongside this one. / 依赖：其他五个目录需与本目录并列保留。

Results: `../06_Hao_Interface_and_Rerun-Hao接口与复跑/Rerun_Results-复跑结果/PP-水分不限/`. / 结果保存在 Hao 文件夹的 PP 复跑目录。

This model does not provide dynamic drainage or irrigation requirements. / 本模式不提供动态排水或灌溉需求。
