# Precipitation Conditions-

- `Aachen_TMY_Weather.epw`: shared weather file.
- `Precipitation_Supplement.json`: 365-day source-month-matched liquid rainfall.
- `Precipitation_Adapter.py`: date/source/hash validation and rainfall attachment.
- `Original_Data/`: original ERA5 response. / ERA5 .
- `Detailed_Method.md`: detailed source and timing assumptions.

This is TMY demonstration weather, not a continuous observed year. Snowmelt and panel redistribution are not implemented.
