# 第二种实验：共同生产目标与相同补给规则

入口：本文件夹 `Start_Target_Inputs-后台启动.ps1`，或运行 `Run_Target_Inputs-计算目标补水补氮.py --workers 2`。
新增代码与原氮淋失扩展放在同一文件夹；使用统一项目内的既有 WOFOST81/SNOMIN 核心、天气和完整季逐点辐射。
`Resource_Target_Engine-目标投入引擎.py` 只新增灌溉/施氮管理信号，不改写 PCSE 作物、水分、氮转运方程或旧计算引擎。

## 研究问题和解释范围

每种作物均以其露天 WOFOST81 潜在可收获器官干物质产量的90%为共同生产目标。露天、普通固定板、半透明固定板采用相同的逐日管理规则。
模型输出规则下的实际补水量、补氮量、产量及氮淋失，并核对目标是否达到。
同一规则不保证同一最终产量；光照限制、管理阈值、应用速率上限和其他胁迫都可能造成目标未达。
报告 `target_status`，包括目标超过该光照处理PP81参考产量，以及未在当前规则下达到目标两种情况。
未达目标时，不能把投入减少解释为“等产量节水/节肥”。
这里没有求解水、氮多目标全局最优，也没有证明所得用量是达到目标的最小投入。若需最低投入，需要另定义成本函数、可行管理约束并开展优化。
所有剂量是本情景的模拟投入，不是田块施肥或灌溉建议。

## 土壤与初始条件

保留原BK50候选剖面的水分保持/导水曲线、密度、200cm剖面深度和105cm参考根深上限。该候选地块距离天气坐标约486m，并非已确认的试验田。
新增 SoilGrids 查询的坐标为6.088E、50.801N。SOC和pH是250m模型预测，不能称作本田块实测。
原始JSON、单位换算信息、下载地址、时间与SHA256保存在04目录 Nitrogen_Inputs/Source_Records。
按原水力层与SoilGrids深度边界拆层；PCSE进一步细分计算层，不更改水力性质。
有机质质量分数=SOC(g/kg)/1000/0.58，与SNOMIN的有机质转碳系数一致。
SoilGrids总氮已归档，但不能当作矿质氮。独立预测的SOC/总氮在深层给出过低的有机C:N，因此没有直接用于有机C:N；C:N采用已有官方示例的参考值17（0–25cm）、25（更深土层），含深层迁移假设。
初始矿质氮采用已有官方示例：0–25cm硝态氮30、铵态氮5 kg N/ha，按厚度分配；更深层设0是明确的参考剖面假设，不是将未知地块值悄悄填零。
初始有效水量沿用旧WLP约定：按整个剖面田间持水量与萎蔫点差计算WAV。PCSE自行分配各层；不表示全季每天补满，也不等于实测初始水分。
这些共同初始条件在同一作物的三个光照处理中完全相同。
原严格地块参数文件仍保留缺项，不被覆盖；本研究估计情景单独保存为 `Aachen_BK50_SoilGrids_Target-目标投入估计情景.json`。

## 逐日管理规则

全部阈值在同目录 `Target_Management-目标管理.json`，属于明确的分析者设定，尚未针对本田块校准。

* 水分：当当前根区剩余有效水量低于有效容量50%，计算恢复到90%所需水深；扣除已知当日降雨，日施水上限5mm，低于1mm不施。假定完全知道当日降雨，未模拟预报误差。
* 灌溉效率：1.0，输出为田间净灌溉量；未考虑输配水、抽水和施用系统损失，不可直接当成取水量或能耗。
* 氮：根据模型当前根区可利用矿质氮，建立“最大日吸氮速率×7天×非固氮份额”的缓冲目标。低于缓冲目标的一半时补足，最短间隔7天、单次不超过80kg N/ha、季总量不超过400kg N/ha，截止DVS1.3。上限是数值管理约束，不是施肥推荐或当地法规限额。
* 肥料：按N当量施入，铵态/硝态各50%，施入深度10cm；没有指定实际商品肥料质量，不能直接把kg N/ha当成kg肥料/ha。
* 大豆：保留来源作物参数中的固氮，常规矿质氮投入上限0；其结果受这一管理规则与固定比例固氮假设约束，不解释为所有条件下都不需要氮补充。
* SNOMIN原实现将入渗水按 `NH4ConcR=1、NO3ConcR=4 mg N/L` 计入溶解氮补给。因此本情景隐含雨水与灌溉水采用相同参考浓度；输出 `wet_N_input_kg_N_ha` 包含这种入渗水氮输入，不能只称为降雨实测沉降。所有三组使用相同浓度。

## 运行与输出

完整季辐射保持原15×15=225点，不用平均辐射替代逐点模型。
六作物×三个光照处理=18组；露天每作物1柱、光伏每组225柱，共2706个管理作物季；另运行同样2706个PP81作物季计算潜在产量参照。
点位管理相互独立，属于理想化的空间精细管理；面积加权后的用量不是按整块田一个阀门统一灌溉的已实施方案。
同一作物同一种光照处理中，各点单位面积权重一致；共同种植面积1024m²。

原始逐点结果与续跑断点：统一项目 `07_Full_Season_Run-完整季运行/target_resource_run`。
每组保存天气、参数、管理规则、点汇总；每点保存逐日作物、分层土壤水氮、管理操作CSV.gz。
每次检查施水/施氮信号累计与实际模型接收量一致，水分与氮收支残差均应小于0.001对应单位。
测试中“取消降雨以检验灌溉”的天气修改仅在06目录 Validation；不进入正式结果。

最终表图：`08_Thesis_Results-论文表格与图片/05_Target_Inputs-目标补水补氮`，表图亦收集到既有01/02汇总目录。
计划六张作物图（产量与目标、净灌溉量、施氮与氮淋失）及一张更新的产量—ET归一化图；英文PNG/PDF/SVG。
归一化分母为相同作物、相同管理规则下的露天输出；露天灌溉或施氮为0时，其比值留空，保留绝对值与差值，不人为改成1。
原PP/WLP73雨养图保留；新图明确标记管理情景，不混称为原WLP。

## 限制与来源

季总量截至每次模拟结束，不是年总淋失；不同成熟日期会影响累计量。淋失边界为整个200cm剖面底部，扣除底层向上一层的内部转运；反硝化及原模型上边界氮输出单列。
没有板面汇水再分配、土壤横向交换、融雪或光伏微气候反馈。辐射仍是既有示例几何、低精度光线追踪结果，未建立数值收敛。
未进行田间校准或观测验证；初始矿质氮、C:N、矿化过程及控制阈值的不确定性仍存在，单一情景不代表稳健性检验。
